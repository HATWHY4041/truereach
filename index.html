The agent pays as it goes

No API keys, no subscriptions. Each request hits buy, gets a price (HTTP 402), signs a stablecoin payment and gets the data — settled on Celo in about a second.

It checks what matters

Median engagement vs. follower count, how many followers actually see posts, posting rhythm, and a follower sample scanned for bot signals: no photo, never posted, brand-new, follow-spam.
